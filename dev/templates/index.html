Outil de conversion LINGO vers Pyomo

Passez de LINGO a un notebook Pyomo sans perdre le fil.

Cet outil permet de convertir un modele LINGO en notebook Pyomo, de traiter les fichiers relies a Excel, de nettoyer un fichier source et, si besoin, de lancer un pipeline complet de preparation.

Nettoyage LINGO

Uniformise la casse, supprime certains commentaires et retire les sections vides avant conversion ou validation.

Le fichier nettoye est affiche en comparaison avec la version source avant telechargement.

Nettoyages appliques

  • Suppression des commentaires entre crochets et normalisation de certains motifs parasites.
  • Uniformisation de la casse pour faciliter le traitement du fichier.
  • Suppression des blocs DATA / ENDDATA vides pour obtenir un fichier plus propre.

Pipeline complet

Le mode le plus autonome: detection OLE, conversion si necessaire, nettoyage optionnel, generation du notebook et export JSON des donnees.

Ce que fait le pipeline

  • Detection d'un eventuel lien Excel dans le fichier choisi.
  • Conversion et nettoyage si necessaire, sans etapes manuelles supplementaires.
  • Generation des fichiers utiles, avec telechargement du notebook et des donnees externes si besoin.

Comment l'utiliser

Voici un parcours simple pour utiliser l'outil selon le type de fichier que vous souhaitez traiter.

1

Choisir l'action adaptee

Utilisez la generation de notebook pour un besoin direct, ou le pipeline complet si votre fichier demande plusieurs etapes.

2

Verifier le cas OLE

Si votre fichier depend d'Excel, utilisez la conversion OLE ou laissez le pipeline le prendre en charge.

3

Relire le resultat

L'apercu permet de verifier rapidement le contenu avant de telecharger le fichier genere.

4

Telecharger le fichier genere

Recuperez ensuite le notebook, le fichier nettoye, la version explicite ou le JSON selon l'action choisie.

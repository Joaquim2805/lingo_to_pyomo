À propos de LingPy

Un outil de conversion LINGO vers Pyomo conçu pour la recherche opérationnelle.

Qu'est-ce que LingPy ?

LingPy est un outil de conversion qui transforme des modèles d'optimisation écrits en LINGO en code Pyomo exécutable dans un notebook Jupyter. Il a été développé dans un cadre académique pour faciliter la transition vers des outils open-source en recherche opérationnelle.

Pipeline de conversion

Le processus de conversion suit plusieurs étapes automatisées :

1

Pré-traitement

Nettoyage du fichier LINGO : suppression des commentaires, normalisation de la casse, retrait des blocs vides.

2

Parsing

Analyse syntaxique avec la grammaire Lark (LALR). Le fichier est transformé en arbre syntaxique abstrait.

3

Transformation

L'AST est converti en dictionnaire structuré (sets, données, contraintes, objectif) puis en code Pyomo.

4

Génération

Le code Pyomo est encapsulé dans un notebook Jupyter avec imports, résolution et affichage des résultats.

Technologies

Python 3.12+
Flask 3.x
Lark (parser)
Pyomo 6.x
nbformat (notebooks)
openpyxl / pandas
highlight.js
Font Awesome

Solveurs supportés

Le notebook généré peut être configuré pour utiliser l'un des solveurs suivants :

HiGHS (défaut)
Gurobi
CPLEX
GLPK
IPOPT

Auteurs

Ce projet a été développé par Fausto Errico, Virginie Destuynder et Joaquim Jusseau dans le cadre d'un projet académique.

Fonctionnalités principales

  • Conversion directe LINGO → Pyomo avec aperçu comparatif
  • Résolution automatique des appels @OLE vers Excel
  • Nettoyage intelligent des fichiers sources
  • Pipeline complet avec export de données JSON ou DAT
  • Traitement par lot avec archive ZIP
  • Vue comparée côte à côte (LINGO vs Pyomo)
